# 数据与代码说明

## 页面构成

`DashboardContent.jsx` 负责四个页面（经营总览、资源位分析、群转化、召回链路）、筛选、KPI 变化、趋势图和表格。`OperationsPanels.jsx` 与 `operations.js` 提供月内同期对比、经营变化摘要、资源位贡献排名。`RateTrend.jsx`、`smooth-path.js` 提供平滑的百分比趋势；`ResourceScatter.jsx` 提供规模与转化率散点图。`dashboard.css` 包含两张柱状图日期完整显示和隔天显示的修复。

公共组件从 `../../data-app-public.jsx` 引入，由 Data 插件运行时提供。本仓库为静态展示快照，直接使用已编译的 `index.html` 即可完整查看。

## 数据结构

数据采用长表记录：`date`、`rowId`、`metric`、`section`、`value`、`rawValue`、`valueKind`、`grain`。`rowId` 是指标键，不是用户标识；没有个人用户记录。

六个查询包括资源位和群转化各自的 `daily`、`monthly`、`history`。日度与历史查询共享同一套模拟日值；月度数量和金额按日累计，存量取月末，已定义的比例按分子分母重算。模拟数据只用于说明页面，不应作为经营结论。

`metrics.json` 为指标字典；`demo-snapshot.json` 为按固定公开种子、固定演示日历（2026-06-01 至 2026-11-07）生成的模拟数据快照，不读取任何原版数据、查询结果、飞书数据或授权配置。

## SQL 文件

1. 在群累计快照：进群规模、留存、累计支付和核销。
2. 进群批次转化：按进群日期观察支付、核销及 30 日内表现。
3. 召回触达转化：首次触达和触达后首次进群的累计统计。
4. 资源位加 C 转化：资源位加 C、当日进群、累计进群和留存。

SQL 保留聚合及关联逻辑，内部库表已替换为 `demo_dw`、`demo_analysis` 下的示例表，群名、策略和渠道为示例值。字段如 `uid`、`union_id` 只是列名，包中没有对应真实值。不同 SQL 使用的筛选条件和归因方式各自保留，尚未改写为统一指标模型，也未对外部数据库运行验证。

公开包不包含原始 SQL 与示例名称的映射表。
