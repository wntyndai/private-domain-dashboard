# 私域新客群监控看板（公开演示版）

这是脱敏后的公开演示项目。页面保留看板布局、月度／日度切换、趋势图和筛选交互，业务数值为示例数据。

## 项目文件

- `index.html`：GitHub Pages 的网页入口，使用脱敏公开版。
- `docs/项目说明.md`：项目用途、运行方式和公开范围说明。

## 本地查看

直接双击 `index.html` 即可打开看板，也可以使用任意静态文件服务器托管。

## GitHub Pages

将仓库的 Pages 来源设置为 `main` 分支的根目录后，即可通过仓库对应的 Pages 地址访问。

## 数据说明

本项目不连接飞书或其他业务数据源，不包含真实经营数据、飞书链接、表格 ID、SQL 和访问凭据。数据仅用于展示页面结构与交互。
