# 私域新客群监控看板 · 公开脱敏演示版

面向私域新客增长场景的经营监控看板，包含四个页面，支持日度/月度切换、同期对比、经营摘要与资源位贡献排名。本仓库为**脱敏公开版**：页面中展示的全部数值均为独立生成的模拟数据，不包含任何真实经营数据或数据源配置。

## 看板包含哪些内容

### 四个页面

| 页面 | 说明 |
| --- | --- |
| 经营总览 | 核心 KPI 的绝对值与环比 / 百分点变化，以及经营变化摘要、月内同期对比 |
| 资源位分析 | app资源位、小程序弹窗、APP新人专区、小程序新人专区四个资源位的加 C、进群规模与转化率，含规模 × 转化率散点图与贡献排名 |
| 群转化 | 进群规模、新增进群规模、新客新增进群等累计与批次转化表现 |
| 召回链路 | 召回触达、触达后进群等转化统计 |

### 通用交互

- 日度 ↔ 月度切换，月度覆盖近 6 个月
- KPI 卡片的绝对值与环比 / 百分点变化
- 经营变化摘要、月内同期对比、资源位贡献排名
- 资源位规模与转化率散点图
- 平滑趋势曲线，百分比轴固定 0%—100%，GMV 以万为单位展示

## 数据说明：本仓库是脱敏公开版

- **原版**：通过 SQL 编写查询逻辑并写入数据库，由飞书文档作为每日数据源，网站内容随飞书源数据的每日更新自动刷新。
- **本公开脱敏版**：不连接数据库与飞书，改用固定种子独立生成的模拟数据（日期区间 2026-06-01 至 2026-11-07），仅用于展示页面结构与交互效果。

因此本仓库**不包含**真实经营数据、数据库连接信息、飞书文档链接或表格 ID、真实库表名、账号及访问凭据。`sql/` 目录仅保留查询逻辑模板，库表、群名、渠道与策略均已替换为示例名称；`data/metrics.json` 为指标字典，`data/demo-snapshot.json` 为模拟数据快照。

## 目录结构

| 路径 | 用途 |
| --- | --- |
| `index.html` | 自包含的离线网页，也是 GitHub Pages 首页，双击即可打开 |
| `src/content/dashboard/` | 看板 React 源码、CSS、日期计算与图表组件 |
| `src/theme.css` | 看板主题 |
| `sql/` | 四份查询逻辑模板（在群累计、进群批次转化、召回触达转化、资源位加 C 转化） |
| `data/metrics.json` | 公开指标字典，仅含名称、分组与数据类型 |
| `data/demo-snapshot.json` | 独立生成的模拟数据快照 |
| `docs/` | 数据结构与 SQL 模板说明 |

## 本地查看

直接双击 `index.html`，或在项目目录执行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8080`。

本仓库作为**静态展示快照**发布，已移除构建脚本，直接使用 `index.html` 即可查看。如需修改源码或数据，请回到原始构建环境中完成后再重新生成网页。
